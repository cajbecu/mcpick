# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion about the code.
Harassment, personal attacks and demeaning comments are not welcome here.

Report a problem through GitHub's private reporting, or by opening an issue if
it can be discussed publicly. Reports are handled by the maintainers, who will
keep the reporter's identity private.
